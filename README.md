# BTS ARIRANG World Tour Tracker (fan-made)

Live site: https://gwguinnie.github.io/Arirang/

Fan-made tracker for BTS WORLD TOUR 'ARIRANG': tour map & schedule, surprise songs, news board, souvenir ticket maker and a surprise-song slot machine.
Not affiliated with BIGHIT MUSIC / HYBE. Souvenir tickets are not real tickets.

- `index.html` — the app (fonts embedded)
- `data.js` — tour dates, surprise songs, albums (updated automatically)
- `news.js` — news board (updated automatically)
